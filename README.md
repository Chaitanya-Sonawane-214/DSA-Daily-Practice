## 🗂️ Folder Structure

Organized by **pattern**, not by date — makes weak areas obvious and revision easy.

```
dsa-daily-practice/
├── README.md
├── 02-Hashing/

```

Folders are created only when a pattern is first attempted — no need to pre-create all of them.

## 📄 File Format

Each problem gets its own file inside its pattern folder:

```
02 - Hashing/striver_longest_consecutive_sequence_in_an_array
```


## ✅ Daily Workflow

1. Solve problem on Striver/LeetCode's own judge first.
2. Copy working code into local file (link + approach + complexity).
3. Update the progress table above.
4. Commit with a clear message:
   ```
   git add .
   git commit -m "feat: Hashing - LC448 Find All Numbers Disappeared in an Array"
   git push
   ```
